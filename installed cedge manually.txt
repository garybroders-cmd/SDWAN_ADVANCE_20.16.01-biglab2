from windows copy pkliCA.pem file to vmanager vshell

scp pkiCA.pem admin@39.1.255.1:/home/admin/pkiCA.pem


copy router pkiCA from router to vmanager /home/admn (default)

scp pkiCA.pem admin@39.1.255.1:/home/admin
 

ls -l on vmanagerf vshell console to check if the file is there

Install this file locally on the server and others as well

request root-cert-chain install /home/admin/pkiCA.pem

Then copy the the validator

from validator vshell

scp admin@39.1.255.1:/home/admin/pkiCA.pem .
